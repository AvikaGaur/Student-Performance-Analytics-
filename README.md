# Student Performance Analytics System

## About the Project
The Student Performance Analytics System is a beginner-level Python project that analyzes student marks and generates useful performance results.

## Technologies Used
- Python
- NumPy
- Pandas

## Features
- Reads student data from a CSV file.
- Calculates total and average marks.
- Assigns grades to students.
- Displays Pass or Fail results.
- Calculates class average, highest average, and lowest average.
- Calculates subject-wise averages.
- Identifies the top-performing student.
- Saves the final results in `final_result.csv`.

## Project Files
- `main.py` – Main program.
- `functions.py` – Functions for calculating marks, averages, grades, and results.
- `students.csv` – Input dataset.
- `final_result.csv` – Generated output file.

## How to Run
1. Install the required libraries:
   `python -m pip install pandas numpy`
2. Keep all project files in the same folder.
3. Run the program:
   `python main.py`

## Learning Outcomes
This project demonstrates the use of Python variables, lists, loops, functions, NumPy, Pandas, CSV files, and basic data analysis.
